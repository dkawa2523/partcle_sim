## Diagnostic Simplification

Ordinary non-faithful runs now default to `output.mode: standard`.

Standard output keeps compact product artifacts:

- `final_particles.csv`
- `solver_report.json`
- `prepared_runtime_summary.json`
- `wall_summary.json`
- `wall_summary_by_part.csv`
- `coating_summary_by_part.csv`

Standard output suppresses deep artifacts unless explicitly requested:

- trajectory arrays and `save_frames.csv`
- `wall_events.csv`
- `runtime_step_summary.csv`
- `source_particle_diagnostics.csv`
- `collision_diagnostics.json`
- `force_contributions.csv`

Compatibility preserved:

- `output.mode: debug` keeps deep artifacts.
- Legacy `output.artifact_mode: full` maps to debug.
- Explicit `output.write_*` flags still override defaults.
- COMSOL faithful configs still force debug output.

Why safe:

- This changes artifact defaults only, not state integration or physics.
- Deep artifacts remain opt-in and are still available to compare/V&V workflows.
- Tests that depend on deep artifacts now request debug or explicit write flags.
